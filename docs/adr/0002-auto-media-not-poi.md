# Android Auto is Media, not POI

Ambient Rotation needs large now-playing Artwork on the head unit. A Gaston-style POI/Car App Library grid fights that UX and still cannot be a free photo browser while driving. Arthur’s **Auto Canvas** uses the **Media** category (browse tree + queue). We reuse **Gaston AA Discipline** (docs, DHU, host-constraint mindset) but do not port POI templates.
