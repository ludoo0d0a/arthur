# Canvas phasing: Auto+TV in v1, wallpaper in v2

Arthur is an ambient product (phone = Control Plane). Shipping phone live wallpaper and OEM AOD in v1 would delay Auto/TV and fight Muzei’s niche too early. **v1 Canvases** = Android Auto + Android TV only; **v2** adds phone live wallpaper (Muzei Pattern); Always-On Display stays after v2 unless explicitly promoted.
