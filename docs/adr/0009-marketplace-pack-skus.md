# Marketplace pack SKUs (Premium is UX-only)

Content unlocks (Personal Photos, Genart topic packs, Custom Fractal) are **sellable packs** via RevenueCat entitlements, not the Premium product. **Premium** remains a lifetime entitlement for **global UX** only (no ads, favorites, and similar). Marketplace browse/buy UI ships on **phone and TV** only — never Android Auto. Canvases still consume owned packs through shared `PackOwnership` gates.
